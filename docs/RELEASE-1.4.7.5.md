# TuinDOOM RT 1.4.7.5

This is the first public TuinDOOM RT source and installer release.

## Included

- Customized ray-traced GZDoom engine source.
- TuinDOOM RT launcher and installer source.
- Doom, Doom II, and custom-WAD launching with IWAD discovery.
- Randomized outdoor sun controls and ray-traced flashlight.
- Luminous ceiling fixtures.
- NashGore with the TuinDOOM RT voxel compatibility package.
- Weapon-mod compatibility mode and saved launcher profiles.

## Requirements

- Windows 10/11 64-bit.
- An RTX/Vulkan-capable GPU with current drivers.
- A legally owned Doom or Doom II IWAD.

## Known issue

The Spider Mastermind now faces, walks, and attacks in the correct direction, but its custom death animation remains unfinished.
