## GZDoom: Ray Traced

The ray-tracing renderer and related integration are derived from the GZDoom: Ray Traced project by Sultim Tsyrendashiev and its contributors. Original project: <https://github.com/sultim-t/gzdoom-rt>.

## NashGore NEXT

The installer bundles `nashgore.pk3`, NashGore NEXT v1.0, copyright 2006–2024 Nash Muhandes. The package is retained intact with its upstream README and license. Its BSD 2-Clause license has a Commons Clause condition: free, non-commercial redistribution is allowed, but the package may not be sold, monetized, crowdfunded, or used to provide a paid service.

The upstream package notes code backported from DISDAIN by Robert “Boondorl” Skutt and sounds from FreeSound contributors. Consult the README and LICENSE inside `nashgore.pk3` for the complete attribution and terms.

## TuinDOOM RT NashGore voxel compatibility

`nashgore_rt_voxel_compat.pk3` adapts NashGore actors and voxel models for this ray-traced engine build. It is intended to be loaded after `nashgore.pk3`.

No commercial Doom IWADs are included. Users must provide legally owned game data.
